# Idan Auto: עריכה אוטומטית לתמונות רכבים ב-Lightroom Classic

Idan Auto לא נכנס ל-Lightroom ולא נוגע בקובצי ה-RAW. הוא מנתח כל תמונה, מבודד את הרכב, מחליט אילו סליידרים להזיז, וכותב ליד כל קובץ RAW קובץ `NAME.xmp`. כש-Lightroom Classic קורא את הקובץ הזה, התמונה נפתחת כבר ערוכה. מבחינת Lightroom זה בדיוק כמו preset, וכל עריכה אפשר לשנות או לבטל.

## התקנה (פעם אחת)

```bash
pip install -r requirements.txt
pip install "rembg[cpu]"      # מומלץ מאוד: בידוד הרכב ב-AI (בלי זה יש בידוד פשוט יותר)
# לא חובה: exiftool (brew install exiftool) לקריאת EXIF מכל סוגי ה-RAW, כולל CR3
```

## שימוש יומיומי

```bash
# 1. בדיקה בלי לכתוב כלום, עם דוח לפני/אחרי
python -m idan_auto run "/Photos/2026-11-07 Showroom" --dry-run --report

# 2. כתיבת קובצי ה-XMP ליד כל RAW
python -m idan_auto run "/Photos/2026-11-07 Showroom"

# עם מודל הסגנון האישי שלך (ראה בהמשך)
python -m idan_auto run "/Photos/2026-11-07 Showroom" --model idan_style.json
```

ואז ב-Lightroom Classic:
- **צילומים חדשים:** מייבאים כרגיל, ו-Lightroom קורא את ה-XMP בעצמו.
- **תמונות שכבר בקטלוג:** מסמנים הכול ובוחרים **Metadata ← Read Metadata from Files**.

## מה הוא בודק ומה הוא מחליט

| מצב | מה נעשה |
|---|---|
| רכב שחור | Shadows גבוה יותר, Blacks פחות אגרסיבי ו-Clarity עדין, כדי שקווי המרכב לא ייבלעו |
| רכב לבן או כסוף | הורדה חזקה של Highlights ו-Whites, איזון לבן **לפי הפח עצמו** כדי שלא יֵצא צהבהב, והורדת רוויה של הצהוב |
| רכב אדום | הורדת רוויה ובהירות של האדום ב-HSL, כי אדום נשרף הכי מהר |
| תאורת אולם או ערב | תיקון גוון הנורות, הפחתת רעש לפי ה-ISO, והרמת צללים |
| היסטוגרמה שטוחה, שרופה או חשוכה | יותר Contrast או Dehaze, הורדת Highlights, או הרמת צללים |
| כל הסט | חשיפה לפי **בהירות יעד לפח** לכל צבע רכב, כך שרכבים שצולמו בשעות שונות נראים כאילו צולמו ברגע אחד |

סדר הניתוח: קודם מודדים את צבע האור מהאולם, אחר כך מנטרלים אותו, ורק אז מסווגים את צבע הרכב. כך רכב לבן תחת נורות צהובות עדיין מזוהה כלבן.

## "ללמוד את הסגנון שלך"

```bash
python -m idan_auto learn "~/Pictures/Lightroom/Lightroom Catalog.lrcat" --out idan_style.json
```

- הקטלוג נקרא מ**עותק**, לקריאה בלבד, כך שזה בטוח גם כש-Lightroom פתוח.
- לכל תמונה שכבר ערכת נשמרים הניתוח שלה והסליידרים שבחרת. בתמונה חדשה המודל מוצא את התמונות הכי דומות ומחקה את מה שעשית בהן.
- המשקל של המודל גדל עם מספר הדוגמאות (עד 85%), והכללים משלימים את השאר. `--model-weight 1` = רק הסגנון שלך.
- אם הקבצים עברו לדיסק אחר: `--path-map "/Volumes/Old/=/Volumes/New/"`.

## כיול

כל המספרים נמצאים בקובץ הגדרות אחד:

```bash
python -m idan_auto config > my_config.json   # עורכים את מה שצריך
python -m idan_auto run FOLDER --config my_config.json --dry-run --report
```

`--target-ev 0.3` מבהיר את כל הסט ב-0.3EV. הדוח (`idan_auto_reports/.../report.html`) מציג לכל תמונה את המקור, הדמיה גסה של העריכה ואת הרכב שזוהה (בירוק), יחד עם הסיבות לכל החלטה.

## מגבלות שכדאי לדעת

- **RAW ו-Lightroom Classic בלבד.** גרסת הענן של Lightroom לא קוראת sidecar. ב-DNG וב-JPEG ה-XMP יושב בתוך הקובץ, ואפשר לכתוב אותו עם `--embed` (דורש exiftool, ומשנה את הקובץ).
- **קריאת מטא-דאטה דורסת עריכות קיימות.** לכן מריצים רק על צילומים חדשים. קובץ XMP קיים לא נדרס בלי `--force`, ואז נשמר גיבוי `.xmp.bak`.
- **מסכות AI** (Select Subject, Sky) לא נכתבות כאן. מחילים אחרי זה preset עם מסכות, למשל מתוך `lightroom-presets/`.
- **כיול ראשוני:** הניתוח מבוסס על תצוגת ה-JPEG שבתוך ה-RAW, שנראית קצת שונה מהרינדור של Lightroom. כדאי להריץ על 20 תמונות, להשוות ב-Lightroom, ולכוונן את `exposure_bias` ואת יעדי החשיפה.
